# Numbered Screenshot Walkthrough

Use these numbered states when documenting the public preview. The walkthrough is intentionally reproducible without requiring learner personal data.

1. **Mission briefing / start** — show the Probability Detective title, age guidance, prediction → experiment → explain framing, privacy statement, and the four navigation controls.
2. **Coin prediction** — select “Around one half” before running the experiment. Show the prediction selected state.
3. **Coin evidence** — run 100 trials. Show Heads, observed proportion, and the two-row count/proportion table. Change P(heads) to demonstrate a biased coin and rerun.
4. **Dice investigation** — select “Two dice: sums 2–12”, run 600 trials, and show both the frequency chart and the equivalent table. Highlight that seven has the largest theoretical probability.
5. **Fair-game design** — enter a valid design whose probabilities add to 1. Show the expected-points table and the simulation evidence with generated wins and observed points/round.
6. **Final challenge** — choose a prediction, submit it, and show the immediate explanation of why design A is fair by expected points.
7. **Completion summary** — open the summary after completing all investigations and the final challenge. Show the completion message and the next-practice prompt.
