# Educator Guide

## Objectives
- Distinguish theoretical probability from observed frequency.
- Explain why finite samples can vary.
- Compare small and larger sample sizes.
- Explain why two-dice sums are not equally likely.
- Reason about fairness using expected points and simulation evidence.

## Prerequisites
Basic fractions/decimals and multiplication. Suggested session: 10–15 minutes.

## Activities
1. **Coin Lab** — predict first, run 10/100/1000 trials, compare observed proportion with the configured theoretical probability, and explore fair or biased coins including the boundary cases P=0 and P=1.
2. **Dice Investigation** — compare one-die faces with two-dice sums. The chart is based on generated trials and the table gives the equivalent numerical view plus theoretical probabilities.
3. **Fair-Game Designer** — design a two-side, non-monetary points game. Probabilities must add to 1. Compare expected points, then inspect a simulation of generated rounds.
4. **Final Challenge** — predict which of two designs is fair, then check the expected-point arithmetic.

## Differentiation
Pairs can make predictions before running experiments. Start with 10 or 100 trials for support; use 1000 trials for extension. Ask learners to explain a surprising observed result rather than treating deviation from theory as an error.

## Safety and privacy
The lesson contains no gambling, betting, payments, login, wallet, learner name, personal information, ads, tracking, chat, uploads, or runtime AI. The game activity uses points only and is explicitly non-monetary.

## Accessibility
The interface uses semantic headings, native form controls, visible keyboard focus, a text table alongside the chart, responsive layout, and reduced-motion support. Core content is designed to remain usable at 360px, 768px, and 1280px viewport widths.
